BaanDee StockGuard

This project runs with a Python API and SQLite. GitHub Pages displays this guide only.

Run the application

  1. Open the repository and choose Code > Download ZIP.
  2. Extract all files and install Python 3.10 or newer.
  3. Double-click START_WINDOWS_FIXED.bat.
  4. Open http://127.0.0.1:8000 and keep the command window open.
